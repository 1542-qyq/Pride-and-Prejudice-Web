# Pride-and-Prejudice-Web
An elegant interactive web application dedicated to Jane Austen's timeless classic Pride and Prejudice . Features character profiles, memorable quotes, film clips, and beautiful vintage-inspired design celebrating the beloved story of Elizabeth Bennet and Mr. Darcy.
一个优雅的《傲慢与偏见》互动网页应用，包含角色介绍、经典台词、电影片段和精美复古设计，致敬简·奥斯汀笔下伊丽莎白与达西的永恒爱情故事。
